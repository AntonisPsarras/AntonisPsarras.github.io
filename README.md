# AntonisPsarras.github.io

Portfolio of Anthony (Antonis) Psarras — maker and developer.

Live site: [https://antonispsarras.github.io](https://antonispsarras.github.io)

Static HTML, CSS, and JavaScript. Open `index.html` locally, or serve the folder with any static file server.

## The Workshop

`/workshop/` is an optional, fictional 3D room built from the projects, using a vendored Three.js build (`vendor/three`, r186.1, MIT) and no build step. The homepage only links to it and never loads Three.js. Serve the folder over HTTP (not `file://`) to try it. See [`workshop/README.md`](workshop/README.md).
