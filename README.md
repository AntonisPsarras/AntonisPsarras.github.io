# AntonisPsarras.github.io

Portfolio of Anthony (Antonis) Psarras — maker and developer.

Live site: [https://antonispsarras.github.io](https://antonispsarras.github.io)

Static HTML, CSS, and JavaScript. Open `index.html` locally, or serve the folder with any static file server.

## The Workshop

`/workshop/` is an optional, fictional 3D room built from the projects, using a vendored Three.js build (`vendor/three`, r186.1, MIT) and no build step. The homepage only links to it, through a portal in the hero (drawn on a 2D canvas) that you can jump into, and never loads Three.js. It plays like a first-person game on desktop (mouse-look, WASD, `E`) and has on-screen controls on phones and tablets. Serve the folder over HTTP (not `file://`) to try it. See [`workshop/README.md`](workshop/README.md).
